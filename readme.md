# 🚀 Go Recon Tool

Быстрый асинхронный CLI-сканер портов, написанный на Go. Предназначен для первичной разведки (Reconnaissance) при проведении аудита безопасности.

## 🛠 Особенности
- **Высокая скорость:** Использование горутин (`goroutines`) и каналов для параллельного сканирования.
- **Удобный CLI:** Флаги управления через библиотеку Cobra.
- **Автономность:** Компилируется в один бинарный файл без внешних зависимостей.

## 📥 Установка и запуск

```bash
# Клонирование репозитория
git clone [https://github.com/ТВОЙ_НИК/go-recon-tool.git](https://github.com/ТВОЙ_НИК/go-recon-tool.git)
cd go-recon-tool

# Запуск сканирования
go run main.go -t scanme.nmap.org -s 1 -e 1024 -w 100
